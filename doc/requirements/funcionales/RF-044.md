# RF-044 — Visualización, generación y exportación de reportes de desempeño (administrador)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-044 |
| Nombre | Reportes de desempeño general (PDF y Excel) |
| Módulo | Administración / Reportes |
| Prioridad | Media |
| Estado | Parcialmente implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige que el administrador visualice, genere y **exporte** reportes de desempeño en formatos PDF y Excel. Neodomus implementa la **visualización de métricas**: `GET /api/v1/reports/resumen` devuelve en JSON el resumen general (ventas totales, pedidos por mes, productos más vendidos, citas por estado y por mes, total de técnicos, clientes, productos y solicitudes pendientes), mostrado en `AdminReportes.tsx` con gráficos. **No existe la exportación en PDF ni Excel**: no hay librerías de generación de documentos en `be/requirements.txt` (verificado: sin `reportlab`, `openpyxl` ni `xlsxwriter`) y no hay endpoints de descarga.

- **Entradas:**
  - Token JWT de administrador.

- **Proceso:**
  i. El administrador abre `fe/src/pages/admin/AdminReportes.tsx`.
  ii. El frontend llama a `GET /api/v1/reports/resumen`.
  iii. `generar_resumen` (`be/app/routers/reports.py`) agrega datos de las tablas `pedidos`, `detalle_pedido`, `citas`, `usuarios`, `clientes`, `productos` y `solicitudes_cuenta`, y devuelve el resumen en JSON.
  iv. La pantalla muestra tarjetas de métricas y gráficas de ventas por mes y citas.
  v. No existen botones funcionales de exportación a PDF o Excel.

- **Salidas:**
  - Resumen de desempeño en JSON y pantalla con métricas y gráficas.
  - Ningún archivo PDF o Excel.

- **Reglas de negocio:**
  - El reporte solo está disponible para administradores.
  - Los datos de ventas provienen de la tabla `pedidos` sembrada, que no se alimenta por el flujo real de compras (el carrito no genera pedidos).

- **Evidencia técnica:**
  - `be/app/routers/reports.py` → `GET /reports/resumen`
  - `be/requirements.txt` (sin librerías de PDF/Excel)
  - `fe/src/pages/admin/AdminReportes.tsx`

- **Observación:**  
  La exportación PDF/Excel está documentada en las user stories (HU-25, HU-42) y la restricción RC-08.6, pero no implementada; también alcanza al rol técnico (RF-027).
