# RF-025 — Subida de fotografías y observaciones al finalizar un servicio (técnico)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-025 |
| Nombre | Subida de fotografías y observaciones al finalizar un servicio |
| Módulo | Módulo del técnico |
| Prioridad | Media |
| Estado | No implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige que el técnico pueda subir fotografías y registrar observaciones al finalizar un servicio. En Neodomus **no existe esta funcionalidad**: no hay endpoints de subida de archivos (no se usa Supabase Storage ni ningún almacenamiento de archivos), no hay tabla para evidencias fotográficas ni campo para observaciones del técnico. El único campo de texto asociado a una cita es `descripcion`, que la llena el **cliente** al crear la cita, no el técnico al finalizar.

- **Entradas:**
  - (No aplica: no existe la funcionalidad.)

- **Proceso:**
  i. No existe ningún flujo de carga de fotos o registro de observaciones del técnico en `be/app/routers/tecnicos.py` ni en las pantallas del técnico.
  ii. Al marcar una cita como Finalizada (RF-024) solo cambia el estado; no se solicitan adjuntos ni comentarios.

- **Salidas:**
  - Ninguna (el estado simplemente se marca como Finalizada).

- **Reglas de negocio:**
  - No implementadas (la user story HU-23 documentaba el alcance, sin implementación).

- **Evidencia técnica:**
  - Ausencia de endpoints de archivos/fotos en `be/app/routers/` (verificado)
  - `be/app/routers/tecnicos.py` → `PUT /tecnicos/citas/{cita_id}/estado` (solo cambia estado)
