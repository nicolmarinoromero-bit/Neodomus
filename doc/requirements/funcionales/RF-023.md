# RF-023 — Consulta de detalles de cada servicio asignado (técnico)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-023 |
| Nombre | Consulta de los detalles de cada servicio asignado (técnico) |
| Módulo | Módulo del técnico |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al técnico consultar el detalle de cada cita asignada. La respuesta de `GET /api/v1/tecnicos/mis-citas` (`TecnicoCitaResponse`) incluye todos los datos operativos: fecha, hora, estado, tipo de servicio, nombre y teléfono del cliente, dirección y descripción, además del `id_cita`. La pantalla `TecnicoCitas.tsx` presenta el detalle de cada cita seleccionada, que es la misma información usada en el dashboard y en el historial.

- **Entradas:**
  - Token JWT de empleado con ficha técnica.
  - Selección de una cita en la interfaz.

- **Proceso:**
  i. El técnico selecciona una cita de su lista (`GET /api/v1/tecnicos/mis-citas`).
  ii. `_serializar_cita_tecnico` (`be/app/routers/tecnicos.py`) compone la cita con los datos del cliente asociado (nombre y teléfono desde la tabla `clientes`).
  iii. La interfaz muestra el detalle: tipo de servicio, fecha y hora, dirección, descripción, datos del cliente y estado.

- **Salidas:**
  - Detalle completo de la cita en pantalla (incluye `telefono` del cliente).
  - Respuesta HTTP `TecnicoCitaResponse`.

- **Reglas de negocio:**
  - El técnico solo puede consultar detalles de citas que le fueron asignadas.

- **Evidencia técnica:**
  - `be/app/routers/tecnicos.py` → `GET /tecnicos/mis-citas`, `TecnicoCitaResponse`
  - `fe/src/pages/tecnico/TecnicoCitas.tsx`, `fe/src/pages/tecnico/TecnicoHistorial.tsx`
