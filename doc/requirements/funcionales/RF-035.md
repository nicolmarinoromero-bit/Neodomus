# RF-035 — Visualización de todos los servicios registrados (administrador)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-035 |
| Nombre | Visualización de todos los servicios registrados |
| Módulo | Administración |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al administrador visualizar todos los servicios registrados en la plataforma, clasificados por estado. Neodomus implementa la vista de citas en `AdminInstalaciones.tsx` con `GET /api/v1/citas/all-admin`, que devuelve todas las citas con los estados del sistema (Pendiente, Confirmada, Finalizada, Cancelada) junto con el cliente asociado (nombre y correo). Adicionalmente, la gestión de productos (`AdminProductos.tsx`) lista los ítems del catálogo clasificados como activos o inactivos, con su estado de stock.

- **Entradas:**
  - Token JWT de administrador.

- **Proceso:**
  i. El administrador abre `fe/src/pages/admin/AdminInstalaciones.tsx`.
  ii. El frontend llama a `GET /api/v1/citas/all-admin`.
  iii. `listar_citas_admin` (`be/app/routers/citas.py`) devuelve todas las citas ordenadas por fecha y hora, con el nombre y correo del cliente.
  iv. La interfaz permite filtrar y revisar el detalle de cada cita y su estado.
  v. Complementariamente, `AdminProductos.tsx` lista el catálogo con su `estado_producto` (activo/inactivo) y estado de stock.

- **Salidas:**
  - Lista de todas las citas del sistema con su estado y cliente.
  - Lista del catálogo con estados activo/inactivo.
  - Respuesta HTTP `List[AdminCitaResponse]`.

- **Reglas de negocio:**
  - Solo el administrador puede acceder a `GET /citas/all-admin` (helper `_admin`).
  - Los estados de cita son: Pendiente, Confirmada, Finalizada, Cancelada.

- **Evidencia técnica:**
  - `be/app/routers/citas.py` → `GET /citas/all-admin`
  - `fe/src/pages/admin/AdminInstalaciones.tsx`, `fe/src/pages/admin/AdminProductos.tsx`
