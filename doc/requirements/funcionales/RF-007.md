# RF-007 — Consulta de precio, descripción y duración estimada de cada servicio

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-007 |
| Nombre | Consulta de precio, descripción y duración estimada |
| Módulo | Catálogo y productos |
| Prioridad | Media |
| Estado | Parcialmente implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al usuario consultar los detalles de cada ítem del catálogo. En Neodomus el detalle muestra **precio de venta, descripción y características** de cada producto, pero **no existe el campo de duración estimada** (no hay columna en `productos` ni en los servicios; la duración de una cita no se modela). La información se muestra en la página de detalle del producto.

- **Entradas:**
  - ID del producto (`producto_id`).

- **Proceso:**
  i. El usuario selecciona un producto del catálogo, lo que abre `fe/src/pages/public/ProductoDetalle.tsx`.
  ii. El frontend llama a `GET /api/v1/productos/{producto_id}` y a `GET /api/v1/productos/{producto_id}/variantes`.
  iii. El backend devuelve los campos del producto: `nombre_producto`, `descripcion_producto`, `precio_venta_producto`, `precio_compra_producto`, `imagen_url`, `colores_producto`, `stock_producto`, `estado_producto`, categoría y variantes.
  iv. La página muestra el detalle con breadcrumb, selección de color (variantes), cantidad y el botón para agregar al carrito.
  v. Algunas características visuales (paleta de colores, características técnicas) están generadas localmente en el frontend según la categoría y no provienen del backend.

- **Salidas:**
  - Respuesta HTTP con el detalle del producto y sus variantes.
  - Pantalla de detalle con precio, descripción, colores, stock y controles de cantidad.

- **Reglas de negocio:**
  - No se expone el precio de compra al público; el precio de venta es el que se muestra.
  - No existe información de duración estimada para servicios ni productos.

- **Evidencia técnica:**
  - `be/app/routers/productos.py` → `GET /productos/{producto_id}`, `GET /productos/{producto_id}/variantes`
  - `be/app/models/producto.py`, `be/app/models/producto_variante.py`
  - `fe/src/pages/public/ProductoDetalle.tsx`
