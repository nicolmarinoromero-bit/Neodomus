# RF-030 — Edición de la información de los técnicos (administrador)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-030 |
| Nombre | Edición de la información de los técnicos (administrador) |
| Módulo | Administración / Gestión de personal |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al administrador editar la información de los técnicos: datos personales, estado de actividad y ficha técnica (certificación y cargo). Neodomus lo implementa con dos endpoints: `PUT /api/v1/users/{user_id}` para los datos del usuario (incluye `is_active`, lo que permite suspender/activar) y `PUT /api/v1/tecnicos/{tecnico_id}` para la ficha técnica. La pantalla `AdminTecnicos.tsx` integra ambos: edita, activa/desactiva y cambia la contraseña de los técnicos.

- **Entradas:**
  - ID del usuario (`user_id`) o del técnico (`tecnico_id`).
  - `EmployeeUpdate`: `first_name`, `last_name`, `email`, `telefono_usuario`, `documento_usuario`, `is_active`, `certificacion`, `cargo`.
  - `TecnicoUpdate`: `certificacion`, `cargo`.
  - Token JWT de administrador.

- **Proceso:**
  i. El administrador abre `fe/src/pages/admin/AdminTecnicos.tsx` y selecciona un técnico para editar.
  ii. El frontend envía `PUT /api/v1/users/{user_id}` con los campos modificados.
  iii. `editar_empleado` (`be/app/routers/users.py`) valida unicidad de correo y documento, aplica los cambios y actualiza/crea la ficha técnica si se enviaron `certificacion`/`cargo`.
  iv. Si se desea ajustar solo la ficha, se usa `PUT /api/v1/tecnicos/{tecnico_id}` (`actualizar_tecnico`).
  v. La lista de técnicos se refresca con `GET /api/v1/tecnicos`.

- **Salidas:**
  - Usuario y/o ficha técnica actualizados en la base de datos.
  - Respuesta HTTP con mensaje de confirmación.
  - Lista de técnicos actualizada en el panel.

- **Reglas de negocio:**
  - El correo y el documento no pueden duplicarse.
  - El rol del usuario no se modifica por esta vía.
  - Solo el administrador puede ejecutar estas operaciones (helper `_admin`).

- **Evidencia técnica:**
  - `be/app/routers/users.py` → `PUT /users/{user_id}` (`editar_empleado`)
  - `be/app/routers/tecnicos.py` → `PUT /tecnicos/{tecnico_id}`, `GET /tecnicos`
  - `fe/src/pages/admin/AdminTecnicos.tsx`
