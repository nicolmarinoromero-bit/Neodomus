# RF-041 — Configuración de los horarios generales de atención (administrador)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-041 |
| Nombre | Configuración de los horarios generales de atención |
| Módulo | Administración / Configuración |
| Prioridad | Baja |
| Estado | No implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige que el administrador pueda configurar los horarios generales de atención de la empresa. En Neodomus **no existe esta funcionalidad**: no hay tabla de horarios, ni endpoints para consultarlos o modificarlos, ni validación de horarios al agendar citas (cualquier hora del formulario es aceptada mientras la fecha no sea pasada). La pantalla `AdminConfiguracion.tsx` es **estática**: solo muestra tres tarjetas con enlaces al perfil del administrador, sin formularios de configuración.

- **Entradas:**
  - (No aplica: no existe la funcionalidad.)

- **Proceso:**
  i. El administrador abre `fe/src/pages/admin/AdminConfiguracion.tsx`.
  ii. La pantalla solo presenta enlaces de navegación hacia el perfil; no hay configuración de horarios.
  iii. `crear_cita` (`be/app/routers/citas.py`) no valida la hora contra ningún horario de atención.

- **Salidas:**
  - Ninguna (la pantalla no ofrece configuración).

- **Reglas de negocio:**
  - No implementadas (la user story HU-39 documentaba el alcance, sin implementación).

- **Evidencia técnica:**
  - `fe/src/pages/admin/AdminConfiguracion.tsx` (contenido estático)
  - `be/app/routers/citas.py` (sin validación de horario de atención)
  - Ausencia de modelos/tablas de horarios en `be/app/models/` y `be/alembic/versions/` (verificado)
