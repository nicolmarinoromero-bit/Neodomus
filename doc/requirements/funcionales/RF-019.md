# RF-019 — Recordatorios automáticos antes del servicio

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-019 |
| Nombre | Recordatorios automáticos antes del servicio |
| Módulo | Notificaciones |
| Prioridad | Baja |
| Estado | No implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige enviar recordatorios automáticos al usuario antes de la fecha y hora programadas del servicio. En Neodomus **no existe ningún mecanismo de recordatorios**: no hay tareas programadas (cron, Celery, APScheduler, BackgroundTasks periódicas), no hay plantilla de correo de recordatorio y no hay configuración de avisos. La documentación del proyecto (HU-18, RF-REQ-08) contemplaba el recordatorio 24 horas antes, pero no está implementado.

- **Entradas:**
  - (No aplica: no existe la funcionalidad.)

- **Proceso:**
  i. No existe ningún proceso que evalúe citas próximas para generar recordatorios.
  ii. `be/app/utils/email.py` solo define dos correos: verificación de cuenta y código de recuperación de contraseña.

- **Salidas:**
  - Ninguna (no se envían recordatorios).

- **Reglas de negocio:**
  - No implementadas.

- **Evidencia técnica:**
  - Ausencia de servicios de tareas programadas en `be/app/` (verificado)
  - `be/app/utils/email.py` (sin función de recordatorio)
