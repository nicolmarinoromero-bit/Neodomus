# RF-017 — Historial de servicios solicitados

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-017 |
| Nombre | Historial de servicios solicitados |
| Módulo | Citas y agendamiento |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al cliente consultar el historial de los servicios que ha solicitado anteriormente. En Neodomus la pestaña "Mis citas" del cliente (`fe/src/pages/cliente/CitasPage.tsx`) lista **todas** las citas del cliente autenticado —pasadas y futuras, en cualquier estado— ordenadas por fecha y hora, lo que cumple la función de historial (hu-stories HU-44 la documentan como "ver historial de servicios anteriores" sin pantalla separada).

- **Entradas:**
  - Cliente autenticado.

- **Proceso:**
  i. El cliente abre la pestaña "Mis citas" de `CitasPage.tsx`.
  ii. El frontend llama a `GET /api/v1/citas/mis-citas`.
  iii. `mis_citas` (`be/app/routers/citas.py`) devuelve todas las citas del cliente, incluidas las finalizadas o canceladas, ordenadas por fecha y hora.
  iv. La interfaz muestra para cada una: tipo de servicio, fecha, hora, dirección, técnico asignado (si existe) y estado.

- **Salidas:**
  - Historial completo de citas del cliente.
  - Respuesta HTTP `List[CitaResponse]`.

- **Reglas de negocio:**
  - El historial solo es visible para el cliente propietario de las citas (filtro por `id_cliente`).

- **Evidencia técnica:**
  - `be/app/routers/citas.py` → `GET /citas/mis-citas`
  - `fe/src/pages/cliente/CitasPage.tsx`
