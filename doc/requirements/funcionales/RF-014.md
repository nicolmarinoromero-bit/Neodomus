# RF-014 — Calificación del servicio y comentarios

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-014 |
| Nombre | Calificación del servicio y registro de comentarios |
| Módulo | Calificaciones y feedback |
| Prioridad | Media |
| Estado | No implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige que el usuario califique el servicio recibido y registre comentarios. En Neodomus **no existe la funcionalidad en el backend**: no hay tabla de calificaciones ni endpoints para enviarlas o consultarlas. En el frontend, la pestaña "Mis reseñas" del perfil (`fe/src/components/profile/ReviewsTab.tsx`) permite interactuar con estrellas (1-5) y comentarios, pero todo se guarda en `localStorage` (`profileStorage.ts`, clave `pf_resenas`) como datos de demostración, sin conexión con el backend ni con los servicios reales.

- **Entradas:**
  - (No aplica: solo datos de demostración en el navegador.)

- **Proceso:**
  i. El cliente abre la pestaña "Mis reseñas" en `Perfil.tsx`.
  ii. `ReviewsTab.tsx` muestra reseñas semilla y permite ingresar estrellas y comentarios.
  iii. Los datos se persisten únicamente en `localStorage`; no se envía nada al servidor.

- **Salidas:**
  - Interfaz de reseñas con datos locales de demostración.

- **Reglas de negocio:**
  - RC-05 / user-stories HU-15 documentan que solo se pueden calificar servicios en estado "completado"; dicha regla **no se implementa** porque no existe el módulo.

- **Evidencia técnica:**
  - `fe/src/components/profile/ReviewsTab.tsx`, `fe/src/utils/profileStorage.ts`
  - Backend: sin modelos ni routers de calificaciones (verificado)

- **Evidencia de ausencia:**
  - Búsqueda de endpoints de rating/reseñas en `be/app/routers/` sin resultados.
