# RF-027 — Generación y descarga de reportes de servicios (técnico)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-027 |
| Nombre | Generación y descarga de reportes de servicios (técnico) |
| Módulo | Módulo del técnico / Reportes |
| Prioridad | Baja |
| Estado | No implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El requisito exige que el técnico genere y descargue reportes de los servicios que ha realizado. En Neodomus **no existe esta funcionalidad**: el único reporte del sistema es `GET /api/v1/reports/resumen` (métricas generales del administrador en JSON), y no hay exportación en PDF ni Excel para ningún rol (ver RF-044). El técnico no tiene pantalla de reportes: `TecnicoHistorial.tsx` solo lista sus citas sin opción de exportar.

- **Entradas:**
  - (No aplica: no existe la funcionalidad.)

- **Proceso:**
  i. No existe endpoint de reportes para el rol técnico.
  ii. El historial del técnico (`TecnicoHistorial.tsx`) se limita a listar citas con filtro de estado y actualización cada 60 segundos, sin generación de documentos.

- **Salidas:**
  - Ninguna.

- **Reglas de negocio:**
  - No implementadas.

- **Evidencia técnica:**
  - `be/app/routers/reports.py` (solo `/reports/resumen` para admin, JSON)
  - `fe/src/pages/tecnico/TecnicoHistorial.tsx`
