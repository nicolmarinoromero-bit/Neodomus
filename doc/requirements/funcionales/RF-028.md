# RF-028 — Consulta de los datos de contacto del cliente (técnico)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-028 |
| Nombre | Consulta de los datos de contacto del cliente (técnico) |
| Módulo | Módulo del técnico |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite al técnico consultar los datos de contacto del cliente asociado a un servicio para comunicarse antes de la prestación. Neodomus lo implementa de dos formas: dentro de cada cita (`GET /api/v1/tecnicos/mis-citas` incluye `cliente` y `telefono`) y mediante la lista de clientes atendidos (`GET /api/v1/tecnicos/mis-clientes` devuelve nombre, correo, teléfono y dirección con el conteo de citas por cliente).

- **Entradas:**
  - Token JWT de empleado con ficha técnica.

- **Proceso:**
  i. El técnico abre sus citas (`TecnicoCitas.tsx`) o la sección "Clientes" (`TecnicoClientes.tsx`).
  ii. Los endpoints `mis_citas_tecnico` y `mis_clientes_tecnico` (`be/app/routers/tecnicos.py`) cruzan las citas asignadas al técnico con la tabla `clientes` para exponer nombre, correo y teléfono.
  iii. La interfaz muestra los datos de contacto del cliente.

- **Salidas:**
  - `TecnicoCitaResponse`: `cliente`, `telefono`, `direccion` por cita.
  - `TecnicoClienteResponse`: `nombre`, `email`, `telefono`, `direccion`, `citas_count` por cliente.
  - Pantallas "Citas" y "Clientes" del panel técnico con dicha información.

- **Reglas de negocio:**
  - El técnico solo ve clientes con los que tiene (o tuvo) citas.
  - No se exponen documentos ni contraseñas de los clientes en estas respuestas.

- **Evidencia técnica:**
  - `be/app/routers/tecnicos.py` → `GET /tecnicos/mis-citas`, `GET /tecnicos/mis-clientes`
  - `fe/src/pages/tecnico/TecnicoCitas.tsx`, `fe/src/pages/tecnico/TecnicoClientes.tsx`
