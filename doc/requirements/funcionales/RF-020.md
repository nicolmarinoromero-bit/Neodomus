# RF-020 — Acceso desde dispositivos móviles, tabletas y computadores (interfaz adaptable)

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RF-020 |
| Nombre | Acceso desde dispositivos móviles, tabletas y computadores |
| Módulo | Experiencia de usuario / UI |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  Permite usar la plataforma desde cualquier dispositivo mediante una interfaz responsiva. La aplicación web Neodomus es totalmente adaptable: se identificaron más de 46 bloques `@media` en los estilos (`fe/src/styles/*.css`) que reorganizan el navbar, las tarjetas, los formularios, el carrito y los paneles en pantallas pequeñas; los paneles de administrador y técnico incluyen menús tipo hamburguesa con sidebar colapsable. Además, el proyecto contiene una primera versión de aplicación móvil nativa (Expo) en `movil/`, aunque actualmente es un esqueleto sin funcionalidad de negocio.

- **Entradas:**
  - (Sin entradas específicas: aplicación web accesible desde el navegador.)

- **Proceso:**
  i. El usuario abre la plataforma desde un móvil, tableta o computador.
  ii. Los estilos CSS adaptan el layout según el ancho de pantalla (puntos de corte en 992 px, 768 px, 576 px, etc.).
  iii. El navbar se apila verticalmente en pantallas pequeñas y los paneles admin/técnico colapsan su sidebar (botones con `aria-label="Abrir menú"`).
  iv. Todos los flujos (catálogo, citas, perfil, paneles) permanecen disponibles en cualquier tamaño de pantalla.

- **Salidas:**
  - Interfaz adaptada al dispositivo en uso.
  - (Complementario) Aplicación móvil `movil/` en estado inicial (Expo), sin funcionalidad operativa aún.

- **Reglas de negocio:**
  - La prioridad de desarrollo documentada es web responsiva primero (RC-03.1).

- **Evidencia técnica:**
  - `fe/src/styles/navbar.css`, `admin-sidebar.css`, `citas.css`, `carrito.css`, `perfil-cliente.css` y demás hojas con `@media`
  - `fe/src/components/layout/Navbar.tsx`, `AdminNavbar.tsx`, `TechnicianNavbar.tsx`
  - `movil/app/` (starter Expo: pantallas de inicio/login/explore)
