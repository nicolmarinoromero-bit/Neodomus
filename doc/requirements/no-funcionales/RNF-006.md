# RNF-006 — Compatibilidad

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RNF-006 |
| Nombre | Compatibilidad |
| Categoría | Plataformas |
| Prioridad | Media |
| Estado | Parcialmente implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El sistema debe funcionar en Windows, Linux y dispositivos móviles Android e iOS.

- **Criterio:**  
  - El backend debe ejecutarse sin modificaciones en Linux y Windows.
  - La aplicación debe ser funcional en navegadores móviles de Android (Chrome) e iOS (Safari), y preferiblemente contar con aplicación móvil nativa.

- **Implementación actual:**  
  - El backend (FastAPI + MySQL) está **contenedorizado en Docker**, por lo que se ejecuta igual en hosts Linux y Windows; los comandos del README (docker-compose) son multiplataforma.
  - La aplicación web es **completamente responsiva** (más de 46 bloques `@media`) y funciona en los navegadores móviles de Android e iOS (ver RNF-007).
  - **La aplicación móvil nativa (`movil/`, Expo/React Native) es un esqueleto sin funcionalidad real**: pantallas de ejemplo del template, login vacío y servicios apuntando a endpoints inexistentes (`POST /login`, `/dispositivos/*`); no cumple funciones de negocio.

- **Evidencia técnica:**  
  - `docker-compose.yml`, `be/Dockerfile`, `fe/Dockerfile` (despliegue multiplataforma)
  - `fe/src/styles/*.css` (media queries) y `fe/src/components/layout/Navbar.tsx`
  - `movil/app/`, `movil/services/` (starter Expo sin funcionalidad)
  - `README.md` → ejecución con Docker
  - `doc/requirements/constraints.md` → RC-03.1, RC-03.4

- **Validación:**  
  - Ejecutar `docker-compose up --build` en Windows y en Linux y verificar que la API responde en ambos.
  - Probar el sitio en navegador móvil Android (Chrome) e iOS (Safari) con las herramientas de desarrollador.
  - Revisar la aplicación `movil/` con Expo Go en un dispositivo real.

- **Observaciones:**  
  - La compatibilidad de escritorio y navegadores móviles está cubierta por la web responsiva.
  - La aplicación móvil nativa Android/iOS está pendiente de desarrollo real (starter de Expo únicamente).
