# RNF-003 — Usabilidad

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RNF-003 |
| Nombre | Usabilidad |
| Categoría | Experiencia de usuario |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  La interfaz debe ser limpia, moderna y comprensible, y un usuario debe poder solicitar un servicio en menos de tres pasos.

- **Criterio:**  
  - Interfaz clara y moderna (diseño coherente, lenguaje en español).
  - Solicitar un servicio en menos de tres pasos desde el catálogo.

- **Implementación actual:**  
  - La interfaz usa React + Vite + TypeScript con una identidad visual consistente (navbar, footer, tarjetas, formularios, modales) y animaciones con Framer Motion; los colores institucionales negro y dorado están en el diseño (RNF-010 de la doc interna).
  - Flujo de solicitud de cita: (1) entrar al módulo de citas, (2) llenar el formulario (tipo de servicio, fecha, hora, dirección) y (3) enviar; es un proceso de una sola pantalla con validaciones en español y mensajes de error accionables.
  - El catálogo es navegable con buscador, filtros por categoría y paginación; el carrito permite ajustar cantidades en un clic.
  - Los paneles (cliente, técnico, administrador) usan navegación con pestañas y menús claros.

- **Evidencia técnica:**  
  - `fe/src/pages/cliente/CitasPage.tsx` (formulario de agendamiento en un solo paso)
  - `fe/src/pages/public/ProductosPublicos.tsx` (buscador, filtros, paginación)
  - `fe/src/components/layout/Navbar.tsx`, `Footer.tsx`, paneles `AdminLayout.tsx` y `TechnicianLayout.tsx`
  - `fe/src/styles/*.css` (diseño coherente y responsivo)
  - `doc/requirements/non-functional.md` → RNF-05.1

- **Validación:**  
  - Realizar la tarea "solicitar un servicio" y contar los pasos (debe ser ≤ 3).
  - Sesiones de prueba con usuarios sin conocimiento previo del sistema.
  - Comprobar que los mensajes de error orientan sobre la corrección.

- **Observaciones:**  
  - Cumple los criterios principales; no existe una auditoría formal de usabilidad (heurística o con usuarios reales) más allá de los flujos implementados.
