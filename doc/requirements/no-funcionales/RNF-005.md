# RNF-005 — Mantenibilidad

- **Identificación:**

| Campo | Valor |
|---|---|
| ID | RNF-005 |
| Nombre | Mantenibilidad |
| Categoría | Calidad de código |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Mayo 2026 |

- **Descripción:**  
  El código debe ser modular para facilitar futuras actualizaciones o cambios sin afectar el sistema completo.

- **Criterio:**  
  - Separación clara de responsabilidades (presentación, lógica, datos, configuración).
  - Añadir o modificar un módulo sin impactar el resto del sistema.

- **Implementación actual:**  
  - **Backend (FastAPI):** estructura por capas — `app/routers/` (endpoints), `app/models/` (ORM), `app/schemas/` (validación), `app/services/` (lógica de negocio), `app/utils/` (seguridad, email, auditoría, limitador), `app/middleware/` (CORS, rate limit) y `app/config.py` (ajustes por entorno). Cada dominio (auth, citas, técnicos, productos, consultas, reportes, solicitudes) vive en su propio módulo.
  - **Frontend (React):** estructura por responsabilidad — `src/pages/` por rol (cliente, técnico, admin, auth, público), `src/components/` reutilizables (layout, perfil, chat), `src/contexts/`, `src/services/`, `src/types/`, `src/utils/` y `src/i18n/`.
  - Esquema de base de datos versionado con **Alembic** (migraciones idempotentes), lo que permite evolucionar el esquema sin reconstruir todo.
  - Configuración por variables de entorno (`.env`) con valores por defecto en `config.py`.

- **Evidencia técnica:**  
  - `be/app/` → routers, models, schemas, services, utils, middleware
  - `be/alembic/` → migraciones versionadas
  - `fe/src/` → pages, components, contexts, services, types, utils, i18n
  - `doc/requirements/constraints.md` → RC-07 (estructura de carpetas obligatoria)

- **Validación:**  
  - Revisar que los módulos cumplen la estructura de carpetas definida (RC-07).
  - Añadir un endpoint nuevo en un dominio y comprobar que no requiere cambios en otros dominios.
  - Ejecutar `pnpm tsc --noEmit` y `pnpm lint` (frontend) y pytest/mypy (backend) para detectar regresiones.

- **Observaciones:**  
  - La modularidad está implementada de forma consistente con las restricciones RC-07 del proyecto.
  - Pendientes de la documentación interna: cobertura de tests ≥ 70% en módulos críticos (solo existe `be/app/tests/test_auth.py`, desactualizado) y docstrings TSDoc completos.
